2025年12月5日(五) 08:00-16:15

🏆 獎項頒發

口頭及海報發表各取 1 名「最佳人氣獎」，每位獲獎者可獲得新台幣壹仟元獎金及獎狀壹張。

📌 注意事項
  • 同一裝置僅限投一次。

🔒 試算表安全權限聲明（不需分享給任何人）：

您的 Google 試算表檔案完全不需要點擊「共用」或提供公開檢視權限。建立好試算表後，請保持最高私人等級。僅有部署後的 Apps Script API 能夠寫入資料，其他人完全無法讀取或竄改您硬碟中的試算表內容！

📋 步驟 1：建立試算表並定義欄位

請開一個新的空白 Google 試算表，在第一行 (Row 1) 依序填入 5 個欄位標頭（如不安裝系統也會自動建立）：
時間 | EMAIL | 口頭投票 | 海報投票 | IP

⚡ 步驟 2：貼上 Apps Script 程式碼

  1. 點選頂部選單「擴充功能」➔「Apps Script」。
  2. 刪除原本預設語法，貼入下方專用程式碼，點選「儲存 (💾)」。
  3. 點選右上角「部署」➔「新增部署」➔ 種類選「Web 應用程式」。
  4. 「執行身份」選「我 (Me)」，「誰可以存取」選「所有人 (Anyone)」。
  5. 點選部署並複製產生的「Web 應用程式網址 (URL)」貼回後台欄位即可完成串接！
